# Smart Playlist Manager 🎵

A menu-driven Music Library Management System developed using C++ for the CSE 2106 – Data Structures and Algorithms Laboratory at Khulna University of Engineering and Technology (KUET).

## Features

- Song Catalog Management
- Search by Title, Artist and Genre
- Browse Songs by Album, Artist and Genre
- Playlist Creation and Management
- Undo Operations
- Recently Played History
- Circular Play Queue
- Related Music Discovery
- Graph Traversal using BFS and DFS
- Sorting using Merge Sort and Quick Sort
- Fisher-Yates Shuffle Algorithm

## Data Structures & Algorithms

| Concept | Application |
|---|---|
| Array | Song Catalog |
| Doubly Linked List | Playlist Management |
| Stack | Undo and Play History |
| Circular Queue | Play Queue |
| Binary Search Tree | Title Management |
| Graph | Related Music Discovery |
| BFS & DFS | Graph Traversal |
| Linear Search | Song Searching |
| Binary Search | Title Searching |
| Merge Sort | Alphabetical Sorting |
| Quick Sort | Play Count Sorting |
| Fisher-Yates | Playlist Shuffle |

## Technologies Used

- C++
- C++11
- GCC / MinGW
- Data Structures and Algorithms

## How to Run

Compile the project:

```bash
g++ -std=c++11 -Wall -Wextra -o smart_playlist main.cpp
```

Run:

```bash
./smart_playlist
```

On Windows:

```bash
smart_playlist.exe
```
